# Test festive effects

Choose an effect to try it on this page at any time of year.

| Effect | URL parameter |
| --- | --- |
| [Snow only](?festive-snow=true) | `?festive-snow=true` |
| [Snow with Father Christmas](?festive-santa=true) | `?festive-santa=true` |
| [Fireworks only](?festive-fireworks=true) | `?festive-fireworks=true` |
| [Drone display only](?festive-drone=true) | `?festive-drone=true` |
| [Fireworks and drone display](?festive-fireworks-drone=true) | `?festive-fireworks-drone=true` |

The combined test starts with fireworks and switches to drones after about
two minutes. The drone-only test starts with drones straight away, and the
Father Christmas test uses a Christmas destination whatever today's date.

Use the controls to pause or hide the effect. If reduced motion is enabled,
choose **Resume** to start it. Fireworks start muted. [Clear the test](?)
to return to this page without an effect.

## Test a Joomla page

Append one parameter to the URL of a public page where Festive Overlay is
enabled. Use `&` instead of `?` if the URL already has a query string. The
value must be `true`. Remove the parameter to return to the site's normal
seasonal schedule. The parameter applies to the page in the link.

<div id="festive-overlay-demo">
<link rel="stylesheet" href="festive-demo/css/overlay.css">
<script src="festive-demo/js/overlay.js" defer></script>
</div>
